# Aldratos Cube Survival: web test build

A **development test build** of Aldratos Cube Survival for trying the game in a browser (desktop or phone). It is not the release.

- Built from `dev` of [Aldratos_Cube_Survival](https://github.com/aldorosenfeldjr/Aldratos_Cube_Survival).
- Ads and purchases are **fakes** (instant, free): they only exist to try the flows.
- A new save starts with **10,000 gems** so everything can be unlocked and tried.
- Progress is stored in your browser; clearing site data resets it.
- Performance and touch behaviour on phones are what this build is for; the real iOS/Android builds will differ.

Engine: Unity 6 (WebGL). Audio starts after your first tap (browser rule). Sounds and music are placeholders.
